協助與支援

一般問題與功能建議可透過專案公開 GitHub Issues 提交。敏感帳號請求請勿送到公開討論區。

更新於 2026 年 11 月 1 日

連線與組桌

請確認四位玩家使用相容版本與同一種聯機服務。跨平台桌使用 EOS；Android 無法加入 Apple 專用 Game Center 桌。目前無法保證所有網路條件都能連通。

練習進度

Apple 版本會在本機儲存練習進度；Android 目前開發版關閉後不能恢復。沒有跨裝置雲端存檔。

連線中斷

有人離開或連線實際中斷時，目前版本會暫停牌桌，需要重新邀請組桌。請保留畫面錯誤描述，勿在公開問題中貼上房間口令。

提交一般問題

建議說明平台與系統版本、應用程式版本、操作步驟、預期結果及實際情況。截圖應先遮擋暱稱、聯機身分、房間口令與其他個人資訊。請勿上傳權杖、密鑰或未檢查的完整記錄。

開啟專案 Issues

帳號刪除與私密請求

目前開發版尚未開放應用程式內帳號刪除申請，私密聯絡管道也尚待確定。請勿透過公開 Issues 提交身分標識或敏感資料；公開發帖、解除安裝與清除快取都不能替代服務帳號刪除。正式流程與處理資訊會於準備完成後更新。

服務方隱私參考

  • Epic Games / EOS
  • Apple / Game Center
  • GitHub Pages / GitHub
