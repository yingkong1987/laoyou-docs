隱私說明

這份說明介紹目前開發版本與本站的資料處理情況。實際營運主體、私密聯絡管道、服務留存與帳號刪除流程仍需在正式發行前確認並完善。

更新於 2026 年 11 月 1 日

適用範圍與維護者

本說明涵蓋一桌老友目前的開發版本與專案文件站。維護者的公開 GitHub 帳號為 yingkong1987；法定營運主體資訊尚待確定，帳號名不應被當作法定人名或公司名稱。

單機練習與裝置資料

單機練習由裝置上的遊戲核心處理，不要求建立聯機身分。Apple 版本在本機儲存練習進度與顯示名稱；Android 目前開發版的練習只保存在執行中的應用程式裡，關閉後不能恢復。目前不提供跨裝置雲端存檔。

跨平台好友桌與訪客身分

使用跨平台好友桌時，Epic Online Services（EOS）會建立並儲存裝置訪客聯機身分。EOS 處理登入、房間成員、連線與傳輸所需資訊；SDK 也會在裝置上保存身分憑證與執行快取。應用程式沒有電子郵件或手機號碼註冊表單。

同桌資料與牌局

暱稱、聯機身分標識、房間成員與公開牌面會按組桌及對局需要提供給服務方與同桌牌友。裝置接收自己的手牌與對局公開資訊，房主裝置負責對局裁決。請勿把房間口令分享給預期同桌以外的人。

Apple 專用好友桌

Apple 專用好友桌使用 Game Center 身分與聯機能力，需完成相應服務設定後提供。Apple 會依其服務規則處理相關資料；同桌不能混用 Game Center 與 EOS。

第三方服務與診斷

EOS 官方 iOS SDK 隱私清單聲明了玩家標識、遊戲內容、產品互動、效能資料與姓名、電子郵件等類別，部分用於分析。應用程式沒有另外接入廣告 SDK；SDK 在本專案實際啟用功能中的處理與留存仍在核驗，正式發行前需完成披露。開發診斷只在專用除錯副本明確啟用時記錄有限的連線事件；正式 Release 不含該本機診斷寫入功能。

剪貼簿與權限

只有主動點選貼上時，應用程式才讀取剪貼簿中的房間口令。複製及分享也由使用者主動操作。目前不提供語音、拍攝或通訊錄匯入功能；網路與區域網路權限用於好友聯機。

保留時間與刪除

離開房間、關閉或解除安裝應用程式、清除本機快取，不等於刪除 EOS 服務中的訪客身分與資料。目前開發版尚未開放應用程式內帳號刪除申請；刪除範圍、處理時間與完成通知仍待核驗。公開 GitHub Issues 不是帳號刪除申請或身分核驗管道，該流程需在正式發行前完成。

支援與敏感資訊

一般問題與建議可透過公開 Issues 回報。請勿公開提交個人資料、聯機身分標識、房間口令、存取權杖、用戶端密鑰或完整診斷記錄。私密聯絡管道尚待確定，請勿為了提出請求而公開敏感資訊。

本站與更新

本站是由 GitHub Pages 託管的靜態文件，沒有表單、廣告、分析腳本或第三方字型。GitHub 可能依其隱私聲明處理網站存取記錄。說明會隨功能與營運安排更新，更新日期列於本頁。
