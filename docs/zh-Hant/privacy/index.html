隱私說明

本說明適用於一桌老友目前開發版本與本站。開發者 Qin Yao 已開放 EOS 訪客身分刪除的應用程式內人工受理，處理與回執資訊見下文。

更新及生效日期：2026 年 11 月 6 日。

適用範圍與發布者

本說明涵蓋一桌老友與本專案文件站。開發者與個人發布者為 Qin Yao；公開支援與隱私聯絡信箱為 support@stackpaste.cn。GitHub 帳號 yingkong1987 是專案維護帳號。

本機練習與裝置資料

20 種已開放玩法的電腦對手在本機計算，不要求建立聯機身分。Apple 的四川血戰與其他玩法分別保留一局練習，開啟對應類型的新局會取代舊存檔；Android 按玩法各保留一局。完成後清理練習存檔，已結束對局可另有僅含公開積分的本機摘要。存檔包含恢復手牌與對局所需資訊，排除自動雲端備份，不跨裝置同步。設定、顯示名稱與電腦難度等偏好也保存在裝置上。

跨平台好友桌與訪客身分

使用跨平台好友桌時，Epic Online Services（EOS）會建立並儲存裝置關聯的訪客身分。EOS 處理登入、房間成員、連線與傳輸所需資訊；SDK 另行保存本機身分憑證與執行快取。應用程式沒有電子郵件或手機號碼註冊表單，這不表示沒有服務身分。

同桌資料與對局

暱稱、聯機身分標識、房間成員、準備狀態、局號、操作、公開牌面與積分按組桌及對局需要提供給服務方與同桌玩家。主持裝置保存並裁決完整對局；其他正常用戶端接收自己的手牌與公開資訊。請只向準備同桌的朋友分享口令，不在暱稱中填寫敏感個人資訊。

原桌恢復記錄

為恢復尚未退出的好友桌，應用程式在本機保存原房間、聯機身分、固定成員與座位、玩法及恢復狀態。主持裝置的私有恢復記錄包含完整手牌、牌牆或棋局歷史；其他成員只保存自己可見的投影。暫時斷線不會主動清除此記錄，明確退出會清除；遺失本機資料、原成員或有效主持狀態，或服務無法恢復原房時，可能無法續局。

Apple 專用好友桌

四川血戰的 Apple 好友桌使用 Game Center 身分、配對、邀請與通訊，需要相應系統、服務與簽名設定。Apple 依其服務政策處理有關資訊。Game Center 與 EOS 不能在同一桌混用，Apple 好友桌不提供與 EOS 相同的冷啟動恢復保證。

第三方服務與診斷

EOS 官方 iOS SDK 隱私清單聲明玩家標識、遊戲內容、產品互動、效能與姓名、電子郵件等通用類別，部分包含分析用途。本應用程式沒有另外接入廣告或分析 SDK，也不提供電子郵件登入。實際啟用功能中的 SDK 蒐集、保留、處理地區與商店隱私標籤仍需核驗。專用 Debug 副本可明確啟用有限的本機連線診斷；正式 Release 不含該診斷記錄器，也沒有自動上傳此類記錄的流程。

剪貼簿與權限

只有主動點選貼上時，應用程式才讀取剪貼簿中的房間口令；複製與分享也由使用者主動操作。目前不提供錄音、拍攝或通訊錄匯入功能，不申請麥克風、相機或通訊錄權限。網際網路與區域網路存取用於好友聯機。

身分刪除與處理狀態

「關於與隱私」提供 EOS 訪客身分刪除申請與進度介面，人工受理服務已啟用。接入該服務的版本從應用程式內發起，不需要另向客服申請才能開始；未設定端點的舊開發版需更新為接入該服務的版本。申請前須明確退出目前或待恢復的好友桌；處理期間可進行本機對局。受理不等於刪除完成，完成狀態須依服務商實際身分與相關資料刪除結果確認。退出、解除安裝、清除快取或公開發帖均不等於服務端刪除。

刪除服務資料與留存

Cloudflare Workers/D1 處理認證申請與回執，Qin Yao 經逐項範圍核對後透過服務商支援的流程處理。短期身分權杖僅在驗證時使用；服務保存加密身分目標、身分與回執校驗值、申請編號、時間與狀態，不保存權杖、明文回執秘密、暱稱或完整對局。發布者 Qin Yao 已確認由本人處理應用程式內刪除申請，正式受理後最長 30 天完成；完成回執在確認刪除完成後保留 30 天。未完成申請不會僅因到期而被清除或標為已刪除。每項刪除依服務商實際結果確認，完成後可在應用程式內查詢回執。服務使用 Cloudflare 託管設施；已觀察到 D1 處理區域為 WNAM，可能涉及跨境處理。服務商平台記錄與備份依其政策處理，不適用本服務完成回執的 30 天期限。

支援與隱私請求

可透過 support@stackpaste.cn 聯絡開發者處理支援或隱私問題；一般問題也可使用公開 GitHub Issues。請先說明應用程式、平台、版本與問題，不寄送存取權杖、用戶端密鑰、回執秘密或完整診斷記錄，不在公開頁面提交身分標識或房間口令。客服信箱用於協助，不能替代應用程式內刪除受理與實際完成回執。

本站與說明更新

本站是 GitHub Pages 靜態文件，沒有表單、廣告、分析腳本或第三方字型。GitHub 可能依其隱私聲明處理網站存取記錄。刪除申請資料由 Cloudflare 與受控營運流程處理，不進入本靜態網站。功能或實際資料處理變更時，我們會更新本說明與日期。
