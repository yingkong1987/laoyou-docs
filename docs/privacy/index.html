开发版本说明

隐私说明

本说明适用于一桌老友当前开发版本与本站。开发者 Qin Yao 已开放 EOS 游客身份删除的应用内人工受理，处理与回执信息见下文。

更新及生效日期：2026 年 11 月 6 日。

适用范围与发布者

本说明覆盖一桌老友与本项目文档站。开发者与个人发布者为 Qin Yao；公开支持与隐私联系邮箱为 support@stackpaste.cn。GitHub 账号 yingkong1987 是项目维护账号。

本机练习与设备数据

20 种已开放玩法的电脑对手在本机计算，不要求建立联机身份。Apple 的四川血战与其他玩法分别保留一局练习，开启对应类型的新局会替换旧存档；Android 按玩法各保留一局。完成后清理练习存档，已结束牌局可另有仅含公开积分的本机摘要。存档包含恢复手牌与牌局所需的信息，排除自动云备份，不跨设备同步。设置、显示名、电脑难度等偏好也保存在设备上。

跨平台好友桌与游客身份

使用跨平台好友桌时，Epic Online Services（EOS）会创建并保存设备关联的游客身份。EOS 处理登录、房间成员、连接与传输所需信息；SDK 另行保存本机身份凭据与运行缓存。应用没有电子邮箱或手机号注册表单，这不表示没有服务身份。

同桌数据与牌局

昵称、联机身份标识、房间成员、准备状态、局号、操作、公开牌面与积分按组桌和对局需要提供给服务方及同桌玩家。主持设备保存并裁决完整牌局；其他正常客户端接收自己的手牌与公开信息。请只向准备同桌的朋友分享口令，不在昵称中填写敏感个人信息。

原桌恢复记录

为恢复尚未退出的好友桌，应用在本机保存原房间、联机身份、固定成员与座位、玩法及恢复状态。主持设备的私有恢复记录包含完整手牌、牌墙或棋局历史；其他成员只保存自己可见的投影。临时断线不会主动清除此记录，明确退出会清除；丢失本机数据、原成员或有效主持状态、服务无法恢复原房时，可能无法续局。

Apple 专用好友桌

四川血战的 Apple 好友桌使用 Game Center 身份、匹配、邀请及通信，需具备相应系统、服务与签名配置。Apple 按其服务政策处理有关信息。Game Center 与 EOS 不能在同一桌混用，Apple 好友桌不提供与 EOS 相同的冷启动恢复保证。

第三方服务与诊断

EOS 官方 iOS SDK 隐私清单声明了玩家标识、游戏内容、产品交互、性能以及姓名、邮箱等通用类别，部分包含分析用途。本应用没有另外接入广告或分析 SDK，也不提供邮箱登录。实际启用功能中的 SDK 采集、保留、处理地区及商店隐私标签仍需核验。专用 Debug 副本可显式启用有限的本机连接诊断，正式 Release 不包含该诊断记录器，也没有自动上传此类记录的流程。

剪贴板与权限

只有主动点击粘贴时，应用才读取剪贴板中的房间口令；复制与分享也由用户主动操作。当前不提供录音、拍摄或通讯录导入功能，不申请麦克风、相机或通讯录权限。互联网与本地网络访问用于好友联机。

身份删除与处理状态

“关于与隐私”提供 EOS 游客身份删除申请与进度界面，人工受理服务已启用。接入该服务的版本从应用内发起，不需要另行向客服申请才能开始；未配置端点的旧开发版需更新为接入该服务的版本。申请前须明确退出当前或待恢复的好友桌；处理期间可进行本机对局。受理不等于删除完成，完成状态须依据服务商实际身份及相关数据删除结果。退出、卸载、清除缓存或公开发帖均不等于服务端删除。

删除服务的数据与留存

Cloudflare Workers/D1 处理认证申请和回执，Qin Yao 经逐项范围核对后通过服务商支持的流程处理。短期身份令牌仅在验证时使用；服务保存加密的身份目标、身份与回执校验值、申请编号、时间及状态，不保存令牌、明文回执秘密、昵称或完整牌局。发布者 Qin Yao 已确认由本人处理应用内删除申请，正式受理后最长 30 天完成；完成回执在确认删除完成后保留 30 天。未完成申请不会仅因到期而被清除或标为已删除。每项删除以服务商实际结果确认，完成后可在应用内查询回执。服务使用 Cloudflare 的托管设施；已观察到 D1 处理区域为 WNAM，可能涉及跨境处理。服务商平台日志与备份按其政策处理，不适用本服务完成回执的 30 天期限。

支持与隐私请求

可通过 support@stackpaste.cn 联系开发者处理支持或隐私问题；普通问题也可使用公开 GitHub Issues。请先说明应用、平台、版本及问题，不发送访问令牌、客户端密钥、回执秘密或完整诊断日志，不在公开页面提交身份标识或房间口令。客服邮箱用于协助，不能替代应用内删除受理与实际完成回执。

本站与说明更新

本站为 GitHub Pages 静态文档，无表单、广告、分析脚本或第三方字体。GitHub 可能按其隐私声明处理网站访问记录。删除申请数据由 Cloudflare 与受控运营流程处理，不进入本静态网站。功能或实际数据处理发生变化时，我们会更新本说明与日期。
