隐私说明

这份说明介绍当前开发版本和本站的数据处理情况。实际运营主体、私密联络渠道、服务留存与账号删除流程仍需在正式发行前确认和完善。

更新于 2026 年 11 月 1 日

适用范围与维护者

本说明覆盖一桌老友的当前开发版本及本项目文档站。项目维护者的公开 GitHub 账号为 yingkong1987；法定运营主体信息尚待确定，账号名不应被当作法定人名或公司名称。

单机练习与设备数据

单机练习由设备上的游戏核心处理，不要求建立联机身份。Apple 版本在本机保存练习进度和显示名，供下次继续；Android 当前开发版的练习只保存在运行中的应用里，关闭后不能恢复。当前不提供跨设备云存档。

跨平台好友桌与游客身份

使用跨平台好友桌时，Epic Online Services（EOS）会创建并保存设备游客联机身份。EOS 处理登录、房间成员、连接与传输所需的信息，SDK 也会在设备上保存身份凭据和运行缓存。应用没有邮箱或手机号注册表单。

同桌数据与牌局

昵称、联机身份标识、房间成员以及公开牌面会按组桌和对局需要提供给服务方及同桌牌友。设备接收自己的手牌和对局公开信息，房主设备负责对局裁决。请不要将房间口令分享给预期同桌之外的人。

Apple 专用好友桌

Apple 专用好友桌使用 Game Center 的身份与联机能力；该入口需完成相应服务配置后提供。Apple 会依其服务规则处理有关数据，同桌不能混用 Game Center 与 EOS。

第三方服务与诊断

EOS 官方 iOS SDK 隐私清单声明了玩家标识、游戏内容、产品交互、性能数据以及姓名、邮箱等类别，部分用于分析。应用本身没有额外接入广告 SDK；SDK 在本项目实际启用功能中的具体处理与留存仍在核验，正式发行前需完成相应披露。开发诊断仅在专用调试副本显式启用时记录有限的连接事件；正式 Release 不包含该本地诊断写入功能。

剪贴板和权限

只有主动点击粘贴时，应用才读取剪贴板中的房间口令。复制或分享也由用户主动操作。当前不提供语音、拍摄或通讯录导入功能；网络和本地网络权限用于好友联机。

保留时间与删除

退出房间、关闭或卸载应用、清除本机缓存，不等于删除 EOS 服务中的游客身份和数据。当前开发版尚未开放应用内账号删除申请，服务身份删除范围、处理时限和完成通知仍待核验。公开 GitHub Issues 不是账号删除申请或身份核验渠道；该流程需在正式发行前完成。

支持与敏感信息

普通故障和建议可通过项目公开 Issues 反馈。请勿公开提交个人资料、联机身份标识、房间口令、访问令牌、客户端密钥或完整诊断日志。私密联络渠道尚待确定，请不要为提出请求而公开敏感信息。

本站与更新

本站是 GitHub Pages 托管的静态文档，无表单、广告、分析脚本或第三方字体。GitHub 可能依其隐私声明处理网站访问记录。说明会随功能与运营安排更新，更新日期列于本页。
