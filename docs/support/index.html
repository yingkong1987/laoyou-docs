帮助与支持

普通问题与功能建议可以通过项目公开 GitHub Issues 提交。敏感账号请求请勿发到公开讨论区。

更新于 2026 年 11 月 1 日

连接与组桌

请确认四位玩家使用兼容版本和同一种联机服务。跨平台桌使用 EOS；Android 无法加入 Apple 专用 Game Center 桌。当前无法保证所有网络条件都能连通。

练习进度

Apple 版本会在本机保存练习进度；Android 当前开发版关闭后不能恢复。没有跨设备云存档。

连接中断

有人离开或连接实际断开时，当前版本会暂停牌桌，需要重新邀请组桌。请保留界面错误描述；不要在公开问题中粘贴房间口令。

提交普通问题

建议说明平台和系统版本、应用版本、操作步骤、预期结果与实际现象。截图应先遮挡昵称、联机身份、房间口令和其他个人信息。不要上传令牌、密钥或未经检查的完整日志。

打开项目 Issues

账号删除与私密请求

当前开发版尚未开放应用内账号删除申请，私密联络渠道也尚待确定。不要通过公开 Issues 提交身份标识或敏感资料；公开发帖、卸载应用和清除缓存都不能替代服务账号删除。正式流程与处理信息会在准备完成后更新。
