Development build notice

Support

Contact support@stackpaste.cn for 一桌老友 support and privacy assistance. Ordinary bugs and suggestions may also use project Issues. Keep sensitive account information out of public posts.

Updated and effective: 6 November 2026.

Joining a table

Gather two, three or four players for the selected game, using compatible app versions and the same multiplayer service. There are currently 10 EOS friend-table games. Android cannot join an Apple-only Game Center table. Keep the app open until all original players connect, synchronize and get ready. Connectivity has not been accepted for every network condition.

Offline practice and progress

All 20 available games offer offline practice. Apple keeps one Sichuan Blood Battle save and one shared save for the other games; Android keeps one per game. Starting a new practice of the corresponding type replaces its previous save, and finished practice saves are cleared. Saves are excluded from automatic cloud backup and do not sync across devices. If saving fails, retain the app and existing record and follow the on-screen retry instructions.

Disconnection and returning to your table

Temporary interruptions pause actions and retain the recovery record. Unless you explicitly leave, the next launch first attempts to return with the original identity, room and seat. This requires the original players, valid host game state and an available service. Reinstalling, losing device records or a room that has ended may prevent recovery. Explicitly leaving stops automatic return to the old table.

Reporting an ordinary issue

Include the app name, platform and OS version, app version, steps, expected result and actual behavior. Redact nicknames, identity identifiers, room codes and personal information from screenshots. Never attach tokens, secrets, receipt secrets or unchecked complete logs.

Account deletion and private requests

Deletion requests and progress are in About & Privacy. Manual intake is active in connected builds; older builds without the endpoint need updating. Requests start in the app, and acceptance and completion are distinct states. Support email can help, but users do not need a separate email exchange to start the in-app process. A public post, leaving, uninstalling or clearing cache does not confirm server-side deletion. Qin Yao will handle formally accepted in-app requests within 30 days. Completed receipts are retained for 30 days after deletion is confirmed.
