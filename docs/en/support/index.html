Support

Use the public GitHub Issues page for ordinary bugs and feature suggestions. Do not post sensitive account requests publicly.

Updated 1 November 2026

Joining a table

All four players need compatible versions and the same multiplayer service. Cross-platform tables use EOS; Android cannot join an Apple-only Game Center table. Connectivity is not yet validated for every network condition.

Practice progress

Apple builds save practice locally. The current Android development build cannot restore practice after closing. There is no cross-device cloud save.

A disconnected table

When a player leaves or a connection actually closes, the current version pauses the table and requires a new invitation. Keep the on-screen error description, but do not post a room code publicly.

Report an ordinary issue

Include platform and OS version, app version, steps, expected result and actual behavior. Redact nicknames, online identifiers, room codes and personal information from screenshots. Never attach tokens, secrets or unchecked complete logs.

Open project Issues

Account deletion and private requests

The development build does not yet offer an in-app deletion request, and a private contact channel has not yet been established. Do not post account identifiers or sensitive data in public Issues. Posting an issue, uninstalling or clearing cache does not delete the provider account. The formal process and processing information will be published when ready.
