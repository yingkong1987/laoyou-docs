Privacy

This notice describes the current development build and documentation site. The legal operator, private contact channel, provider retention and account-deletion process still need to be confirmed before a public release.

Updated 1 November 2026

Scope and maintainer

This notice covers the current development build of 一桌老友 and this documentation site. The public project maintainer is GitHub account yingkong1987. A legal operator name has not yet been confirmed; the account identifier is not presented as a legal personal or company name.

Offline practice and device storage

Offline practice runs through the game core on the device and does not require an online identity. Apple builds save practice progress and the display name locally. The current Android development build keeps practice in the running app only; it cannot be restored after closing. There is no cross-device cloud save.

Cross-platform tables and guest identity

Using a cross-platform friend table creates and retains a device-based guest identity through Epic Online Services (EOS). EOS processes information needed for sign-in, room membership, connections and transport. Its SDK also stores identity credentials and runtime cache on the device. The app does not offer an email or phone-number registration form.

Table and game data

Display nicknames, online identity identifiers, room membership and public game information are shared with the provider and invited players as needed for the table. Devices receive their own hand and public game information; the host device adjudicates play. Share a room code only with the intended three friends.

Apple-only tables

Apple-only tables use Game Center identity and multiplayer services and require their service configuration to be completed. Apple handles related information under its own service policies. Game Center and EOS cannot be mixed within one table.

Providers and diagnostics

The official EOS iOS SDK privacy manifest declares player identifiers, gameplay content, product interaction, performance data, name and email categories, including some analytics purposes. No additional advertising SDK has been added. Processing and retention for the enabled SDK features are still under review and must be reflected in the final release disclosures. Limited development connection diagnostics require explicit activation in a dedicated Debug copy; Release does not include that local diagnostic writer.

Clipboard and permissions

The app reads an invitation from the clipboard only when the player actively pastes it. Copying and sharing are also player actions. The current app has no voice, camera or contacts-import feature. Internet and local-network access support multiplayer connections.

Retention and deletion

Leaving a room, closing or uninstalling the app, or clearing its local cache does not delete the EOS guest identity and provider data. The development build does not yet offer an in-app account-deletion request. Provider deletion scope, processing time and completion notices remain to be verified. Public GitHub Issues are not an account-deletion or identity-verification channel. This process must be completed before a public release.

Support and sensitive information

Use public project Issues for ordinary bugs and suggestions. Do not post personal data, online identity identifiers, room codes, access tokens, client secrets or complete diagnostic logs. A private contact channel has not yet been established; do not disclose sensitive information to make a request.

This site and updates

This is a static GitHub Pages site with no forms, ads, analytics scripts or third-party fonts. GitHub may process site-access records under its privacy statement. This notice will be updated as the product and operating arrangements change; the update date appears on this page.
