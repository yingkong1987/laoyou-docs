一桌老友

A familiar group. A table together.

一桌老友 brings Mahjong, card games and board games into one clubhouse. The current app offers 20 offline games; 10 also support friend tables joined by room code. Each in-app game card explains its available modes and specific house rules.

Current statusSupport

Updated and effective: 6 November 2026.

Friend tables by code

Gather two, three or four players for the selected game. Connect, synchronize and get ready before starting, then stay at the table for another round. Friend tables need an available internet connection.

Offline practice and saves

All 20 available games offer computer opponents that run on the device. Both Apple and Android save practice progress locally, without cross-device cloud saves. The interface supports Simplified Chinese, Traditional Chinese, English, Japanese and Korean.

Entertainment points

Points are for play only. There are no purchasable chips, withdrawals, cash redemption or prizes. Mahjong, card and board games use the rule scope explained in the app.

Current status

The project is preparing for TestFlight acceptance. Multiplayer, installation, independent-network and physical-device behavior, and the complete service lifecycle still require continued acceptance testing. This page is not an App Store release announcement.

Temporary interruptions pause actions and retain a private recovery record. Unless you explicitly leave, the app attempts to return with the original identity, room and seat. Recovery requires the original players, valid host game state and an available service; not every interruption can be recovered.

Manual EOS guest-identity deletion intake is active. Connected builds offer requests and progress in About & Privacy. Qin Yao handles accepted requests within 30 days and retains completed receipts for 30 days. Acceptance does not mean deletion is complete.
