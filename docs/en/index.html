一桌老友

Mahjong with friends.

一桌老友 is a Mahjong project for familiar groups. Invite three friends with a room code, or practise with computer players.

Current statusSupport

A code for your table

One player creates a table and the other three paste the code to join. Get ready together and stay at the same table for another round.

Sichuan Mahjong and practice

The current rules are a casual Sichuan Blood Battle variant. Three computer players are available for practice. Further rules depend on future releases.

Entertainment points

Points are for play only. There are no purchasable chips, cash redemption or prizes.

Current status

The project is in development and acceptance testing. Cross-network and relay reliability, physical-device testing, account deletion and release preparation are not complete. Release information will be announced by the project.

Friend tables require four human players and an available internet connection. A disconnected table currently needs a new invitation.
