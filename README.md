# 一桌老友文档站

一桌老友的现有静态 GitHub Pages 文档站。开发者与个人发布者为 **Qin Yao**，公开支持与隐私邮箱为 **support@stackpaste.cn**。说明更新及生效日期为 **2026-11-06**；这不代表应用已在 App Store 正式发行。

- 简体中文：首页 `/`，隐私 `/privacy/`，支持 `/support/`
- 繁體中文：`/zh-Hant/`、`/zh-Hant/privacy/`、`/zh-Hant/support/`
- English：`/en/`、`/en/privacy/`、`/en/support/`

当前应用提供20种本机练习玩法，其中10种支持按玩法建立两人、三人或四人好友桌；游戏内界面有简体中文、繁体中文、英文、日文和韩文资源。具体房规、模式及恢复限制以游戏内说明为准。Apple和Android都保存本机练习，不跨设备云同步。

EOS游客身份删除的认证人工受理服务已经启用，接入该服务的版本从应用内“关于与隐私”发起并查询进度。Qin Yao本人逐项核对目标与关联产品范围后在Epic执行受支持的删除：正式受理后最长30天完成，实际确认完成后的回执保留30天。用户无需先发邮件才可启动删除；客服邮箱提供协助。受理、宽限处理中和真实删除完成必须区分，不凭时间或登录失败推断完成。不将未知或跨产品范围的目标直接删除。

网站只有静态HTML、CSS和本地图片，没有脚本、表单、分析SDK、第三方字体或构建依赖。认证删除由独立Cloudflare Workers/D1服务处理，静态站不处理身份或保存申请。发布使用现有 `yingkong1987/laoyou-docs` 的 `main` 分支 `/docs`，保留现有Pages和HTTPS设置。

公开站点不得包含游戏源代码、EOS配置、令牌、客户端或服务密钥、身份标识、回执秘密、完整诊断日志、私密App Review联系方式或运营私有证据。普通问题可使用Issues，敏感请求使用公开邮箱私下联系；不自动发送Issues或邮件。

本轮仅更新九个中繁英HTML与本README。完整已签名客户端验收、独立网络与真机行为、专用真实删除测试最终完成及本机旧凭据清理仍分别跟踪；文档发布不代替这些验收。
