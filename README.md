# 一桌老友文档站

纯静态 GitHub Pages 源码，参考 StackShot 的文档仓库结构，使用 `main` 分支的 `/docs` 发布。

- 简体中文：首页 `/`，隐私 `/privacy/`，支持 `/support/`
- 繁體中文：`/zh-Hant/`、`/zh-Hant/privacy/`、`/zh-Hant/support/`
- English：`/en/`、`/en/privacy/`、`/en/support/`

站点没有脚本、表单、分析 SDK、第三方字体或构建依赖。语言通过独立页面切换。

拟定仓库：`yingkong1987/laoyou-docs`；公开支持入口为该仓库 Issues。维护者账号不是法定运营主体名称。运营主体与私密联络渠道尚待确定；本页面不代替尚未完成的应用内账号删除流程。

发布前请审核隐私与开发状态说明，确认 Issues 可访问，在 GitHub Settings → Pages 选择 Deploy from a branch → main → /docs。不要把游戏源代码、EOS 配置、日志、身份标识、密钥或运营私密资料放进此仓库。

页面发布不表示游戏已上架、网络验收通过或账号删除已实现。
